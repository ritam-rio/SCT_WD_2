# ⏱ Premium Stopwatch

## 📌 Project Overview

This project is a **Premium Glassmorphism Stopwatch Web Application** developed as part of the **SkillCraft Technology Web Development Internship (Task 2)**. It features a modern black glassmorphism interface with smooth animations, lap tracking, keyboard shortcuts, and a fully responsive design that provides an elegant user experience across all devices.

---

## 🚀 Features

- High-precision stopwatch
- Start, Pause, Reset controls
- Unlimited lap recording
- Live lap counter
- Fastest lap detection
- Slowest lap detection
- Scrollable lap history
- Keyboard shortcuts
- Premium black glassmorphism UI
- Neon hover effects
- Responsive design
- Smooth animations
- Cross-browser compatibility

---
